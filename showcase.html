图库与流媒体展厅 (gallery.html)

零服务器成本超清视频点播 · iOS Safari 深度调优 · 免翻直传 GitHub Releases

HTTP 206 深度中继

💥 踩过的大坑与死胡同

  • iOS Safari 黑屏崩溃：GitHub Release 原始直链下发的是纯静态附件流，iOS WebKit 严格要求 `Accept-Ranges` 和字节范围响应，直接贴链接在 iPhone 上点击即黑屏或报错。
  • 无法随意 Seek 拖拽进度条：因为缺失 Range 分片响应头，用户在视频进度条上点击任意位置，视频强制从第 0 秒重新拉流。
  • 手机直传被 GFW 掐断：40MB+ 4K 视频在国内手机通过移动蜂窝网络直接向 GitHub 发起 Upload 经常因 SNI 阻断导致连接超时、上传 99% 失败。

💡 最终精妙破局方案

  • HTTP Range 206 深度流式中继 (`/api/video.js`)：在 Cloudflare 边缘函数拦截客户端视频拉流请求，解析 `Range: bytes=START-END`，自动向下游发起分段抓取，重写 `Content-Range: bytes START-END/TOTAL`，完美解锁 iOS 原生全屏与任意拖拽秒播！
  • 双向边缘管道免翻直传 (`/api/upload-asset.js`)：手机端先直传国内无阻断的 Cloudflare 边缘节点，再由 Cloudflare 通过境外骨干直连以无损 Stream 管道分块灌入 GitHub Releases，彻底解决大文件上传痛点。
🔄 框架流程与时序逻辑
Step 01 客户端嗅探 iPhone 发送 Range 头部请求视频前 2KB 字节用于提取 MP4 容器 Meta 元数据。
Step 02 边缘动态切片 Cloudflare Function 计算分片区间，向下游透明抓取指定字节范围。
Step 03 HTTP 206 组装 注入 Content-Range 与 Partial Content 标头，实现无缝拖拽秒播。

英语词库与认知展厅 (vocab.html)

11,160 词条全量离线检索 · Cloudflare D1 边缘数据库 · 客户端 IndexedDB 预热

D1 + IndexedDB 协同

💥 踩过的大坑与死胡同

  • 海量词条与数据库免费配额矛盾：全量词库高达 11,160 词条，若每次用户敲击键盘都在云端 D1 执行全文 `LIKE '%xx%'`，高并发下极易触碰 D1 每日免费读行上限，且网络往返带来明显打字顿挫感。
  • 弱网/地铁断网彻底瘫痪：移动端如果在地下车库、高铁或无网络环境下背单词，纯云端数据库直接导致页面报错白屏。

💡 最终精妙破局方案

  • 首屏分页 + 客户端后台无感预热 IndexedDB：首屏仅从 D1 边缘按需拉取前 60 个词保证 80ms 极速开屏；后台自动静默拉取并在浏览器原生 **IndexedDB** 建立全量词汇前缀树。
  • 归一化小写词头索引 (`head_lower`)：数据库与本地库均对词头进行小写无符号预处理，结合前缀树匹配，二次搜索直接命中本地 IndexedDB，做到 **0 网络依赖、0 数据库开销、0ms 即输即出**！
🔄 框架流程与时序逻辑
阶段一 毫秒级首屏加载 D1 边缘执行带 LIMIT 60 快速分页，优先呈现界面，杜绝首屏阻塞。
阶段二 IndexedDB 离线灌库 后台空闲线程分批载入 11,160 词条，建立本地持久化事务。
阶段三 纯离线即输即出 键盘每敲击一次字母，直接检索本地前缀索引，彻底脱离网络束缚。

资源网盘全球分发展厅 (pan.html)

突破 GitHub Releases 限速 · 全球边缘中继代理 · 多线程分块与断点续传

CDN 边缘代理中继

💥 踩过的大坑与死胡同

  • GitHub Release 直链国内限速或阻断：45MB+ 的 Clash 安装包如果直接给 GitHub Release 原始直链，国内多地宽带频繁遇到 DNS 污染或限速至几十 KB，用户下载体验极差。
  • 常规反代导致断点续传失效与文件名乱码：简单套 Nginx 反代如果忽略了 `Content-Disposition` 附件标头和 `Accept-Ranges`，会导致浏览器下载保存为神秘无后缀文件，且一旦断网只能重头下载。

💡 最终精妙破局方案

  • 边缘函数智能中继网关 (`/api/download.js`)：预设客户端专属别名路由（`cmfa`、`clashverge`），自动跟随上游 302 重定向到 GitHub 核心 CDN。
  • 全标头保真透传：透传 `Accept-Ranges: bytes` 与带有 UTF-8 编码的 `Content-Disposition`，完美兼容浏览器自带下载器、IDM、迅雷等多线程分块并发下载与断点续传，国内跑满百兆带宽！
🔄 框架流程与时序逻辑
路由 01 短别名安全寻址 用户请求 /api/download?file=cmfa，隐藏真实 GitHub 上游仓库路径。
中继 02 边缘并发管道转发 Cloudflare 国际高速光纤直连 GitHub Release CDN，以流式通道穿透回国。
下发 03 多线程与断点续传 下发原生分块与附件文件名，支持任意下载工具跑满家庭宽带带宽。

远程穿透与双机场中枢厅 (clash.html / pan.html)

跨 NAT 反向长轮询信标 · 破解 Cloudflare 5秒盾 · 方案 B 私人固定中继 · 权威计费流校准

反向信标 + 自愈中继

💥 踩过的大坑与死胡同

  • 无公网 IP 跨 NAT 无法入站：家用宽带光猫没有公网 IP，外部 5G 手机无法主动向家中电脑发起 TCP 连接，无法控制电脑端 Clash Verge 换线测速。
  • 第三方机场 5 秒盾与频繁换域：机场开启了 Cloudflare Managed Challenge（人机验证盾），纯后端脚本无法登录；且分发域名频繁被墙，每次换域都需逐台设备重改配置。
  • 官方接口延迟导致流量为 0：官网 `/user/info` 数据库由于未及时刷盘，导致查出来的已用流量为 0，前端剩余流量显示失真。

💡 最终精妙破局方案

  • 反向长轮询信标总线 (`Inverted Beacon`)：将“外网推”变为“电脑内网拉”。电脑端静默守护脚本 `clash_daemon.pyw` 定期向云端 D1“信箱”拉信并执行；75秒滑动心跳窗口精确判定电脑在线状态。
  • 方案 B 私人专属固定免密中继 (`/api/sub.js`)：客户端永远填固定直链；云端自动伪装 `ClashMeta` 客户端指纹绕过 5 秒盾；云端维护多域名池自动探活自愈！
  • Subscription-Userinfo 权威计费标头嗅探：直接向节点直链嗅探权威流量标头，精准核算真实已用/剩余流量！
🔄 框架流程与时序逻辑
信令总线 内网反向长轮询 家庭电脑穿透 NAT 主动请求云端 D1 数据库信箱，规避端口映射限制。
协议伪装 Clash 指纹破盾 注入 ClashMeta 客户端标识，触发官方放行白名单，免验证码获取 YAML。
容灾自愈 多域名自动探活 后台自动探活 dash/sub/api 域名池，主力域名失效时秒级无感切换。

沙县外卖记账与容灾厅 (takeout.html)

离线优先轻量本地事务 · Cloudflare KV 全球分布式双向备份 · 独立安全密码隔离

KV 分布式容灾

💥 踩过的大坑与死胡同

  • 纯本地存储的毁灭性丢失：如果账单仅存放在浏览器 LocalStorage 中，一旦手机系统清理垃圾缓存、清理微信内置浏览器数据或更换设备，记账记录瞬间蒸发。
  • 传统云端数据库成本过高且网络依赖强：搭建专用服务器与 MySQL 运维繁重，且每次点餐都必须网络良好才能记账，网络差时无法记账。

💡 最终精妙破局方案

  • 本地事务优先 + Cloudflare KV 原子级异步双向备份：在手机端本地离线秒记，极度丝滑；网络畅通时调用 `/api/takeout` 异步沉淀至 **Cloudflare 全球分布式 KV 存储 (`TAKEOUT_KV`)**。
  • 多设备无缝漫游与独立访问隔离：换手机或换电脑后，输入访问密码（初始 `8888`），云端自动拉取最新的增量备份，实现数据零丢失与多端自动漫游。
🔄 框架流程与时序逻辑
本地优先 零延迟离线记录 点餐记账实时写入本地持久化，断网依然秒开秒记。
云端同步 KV 分布式异步备份 联网后自动序列化完整账单快照，上传至 Cloudflare Edge KV 容灾节点。
多端漫游 跨设备安全拉取 新设备输入密码解锁后自动双向合并，终结数据丢失隐患。
